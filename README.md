# Briefankündigung für Home Assistant

Add-on, das die Briefankündigungen der Deutschen Post („Ein Brief ist unterwegs zu Ihnen“) aus deinem
Postfach (IMAP, z. B. GMX) liest – mit Absender und Bild des Umschlags. Dazu gibt es ein iPhone-Widget
(Scriptable), das die angekündigten Briefe als Vorschau zeigt.

**Installieren:** Einstellungen → Add-ons → Add-on-Store → ⋮ → Repositories →
`https://github.com/Teyro/Briefankuendigung-HA` hinzufügen, dann „Briefankündigung“ installieren.
Details: [DOCS.md](briefankuendigung/DOCS.md).
